I made DexterOs because I watched the show over the summer and have been obsessed with it ever since. I always enjoy a good show and this was no exception. I wanted to make an operating system that could effectively capture the depth of what a character like this would want and how he could use it for his double life. Obviously I dont want to help serial killers or criminals but I do think a kind of privacy focused OS is a cool concept. There isnt many privacy features that set this apart from others but there are some like the evidence locker and such. Anyways i hope you enjoy using dexterOS as much as i have.
